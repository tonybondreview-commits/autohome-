# AutoHome

Launcher Android per la radio dell'auto (10,25", 1920×720).

Questo repository contiene solo le **versioni pubblicate** (sezione *Releases*).
AutoHome controlla da sola l'ultima release e propone l'aggiornamento:
**Menu › Aggiornamenti**.

Ogni release contiene:
- `AutoHome.apk` – l'app
- `version.json` – numero di versione e novità, letto dall'app
