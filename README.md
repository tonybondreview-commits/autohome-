# AutoHome

Launcher Android per la radio dell'auto (10,25", 1920×720).

Questo repository contiene solo le **versioni pubblicate**, nella cartella `update/`.
AutoHome controlla da sola quella cartella e propone l'aggiornamento:
**Menu › Aggiornamenti**.

La cartella contiene:
- `AutoHome.apk` – l'app
- `version.json` – numero di versione e novità, letto dall'app
